# danapeh.com — authoritative academic profile

Built from the supplied 2026 CV. The site is intentionally research-led.

## Main sections
About; Research; Publications; Grants; Academic Appointments & Leadership; Conferences; Supervision; Teaching; Professional & Community Service; Downloads; Contact.

## Publish
Upload the complete folder to your hosting account and point `www.danapeh.com` to the web root. The site is static HTML/CSS/JS and needs no database.

## Replace / add
- `assets/` contains the CV.
- Replace the portrait placeholder in `index.html` with a professional headshot.
- Add lecture notes/presentations under `assets/resources/` and link them from the Teaching section.
- Add research photographs to a gallery if desired.
